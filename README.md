# broadcast

The website of Matan Navon, sports commentator. Static HTML, Hebrew RTL, no build step.

- `index.html`: the page (a card per sport; each card holds the reels first, then single clips)
- `assets/js/clips.js`: all the content. `mediaBase` is the one place the media host is set
- `assets/js/site.js`: cards, clip sheet, contact
- `assets/css/site.css`: design

Videos and posters are not in this repo. They are served from Cloudflare R2.
